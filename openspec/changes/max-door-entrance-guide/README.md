# max-door-entrance-guide

Teach how to make Max enter Intro from the door and walk to the level start using the saved markers and navmesh, without implementing the behavior.

Start with [the guided exercise](design.md#guided-exercise). The [specification](specs/max-door-entrance-instructions/spec.md) defines what the instructions cover. This change is documentation-only; the learner will make and test the game changes separately.
